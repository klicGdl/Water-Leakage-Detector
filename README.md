# Water-Leakage-Detector
A water leakage detector is a smart device that monitors household water usage in real time. It uses sensors and data analytics to identify hidden leaks or abnormal consumption patterns early, helping prevent property damage, reduce utility costs, and support sustainable water use.

  The KLIC Team will begin this project in September 2025.

Step 1:
The first step is to start with project documentation and a clear definition of the project idea. This will support the PAS (Product Architecture Specification) pathfinding phase, helping the team identify potential available components to consider in the PAS Product Architecture Specification. It will also highlight opportunities to define new electronic components that could help reduce product costs.

Step 2:
The second step is to define small objectives and create team tasks to initiate activities. Some of these tasks will involve analyzing and investigating new components that meet the product’s expectations.
